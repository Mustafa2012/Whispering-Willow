# Whispering-Willow

## Shared product administration

Products are stored in Supabase so additions are visible to every visitor. Create a `products` table with this SQL in the Supabase SQL editor:

```sql
create table products (
	id bigint generated by default as identity primary key,
	name text not null,
	category text not null,
	price text not null,
	description text not null,
	image text not null,
	created_at timestamptz not null default now()
);
```

In Supabase Storage, create a public bucket named `product-images` so dragged product images can be displayed to every visitor.

Set the variables from `whispering-willow/.env.example` in the deployment environment. The service-role key stays server-side; never expose it as a `NEXT_PUBLIC_` variable. The Admin control then uses the configured password to add products globally.

Open `/admin` from the storefront footer to view, add, edit, and remove products. Enter the configured admin password on that page before saving changes.
